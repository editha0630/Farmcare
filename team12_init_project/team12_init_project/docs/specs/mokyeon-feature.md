# 스펙 — 고령 농지 소유자용 간편 신청서

작성: 홍목연  
작성일: 2026-10-29  
근거: `docs/whytree/mokyeon.md`의 "신청 양식 만들기" 노드, grill-me 인터뷰에서 합의한 5개 결정  
상태: 스펙 확정, P0 구현 (`prototypes/mokyeon/index.html`)

---

## 1. 한 줄 요약

유휴농지를 가진 고령 소유자가 **혼자서도 쉽게** 이름, 연락처, 농지 위치, 면적, 희망 활용 방식을 입력하고, 마지막에 입력 내용을 한눈에 확인하는 신청서 화면을 만든다.

## 2. 이 기능이 돕는 WhyTree 노드

```
- 고령 소유자의 유휴농지를 안심하고 관리·활용하도록 돕기
  - 상담·참여 장벽 낮추기
    - 신청 양식 만들기                  ← 이 기능
      - 쉬운 디지털·종이 신청서 제공하기
```

## 3. 제약

- **정적 HTML 파일 한 개**. CSS와 JS는 파일 안에 넣고, 외부 라이브러리를 쓰지 않는다. 파일을 더블클릭하거나 GitHub Pages로 열어도 동작해야 한다.
- **서버 없음, 저장 없음**. 입력값은 어디로도 전송하지 않고 `localStorage`도 쓰지 않는다. 새로고침하면 모두 지워진다.
- 이 화면은 **견본**이다. 실제 접수는 이루어지지 않는다는 점을 화면에 밝힌다.

## 5. 입력 항목

| 단계 | 항목 | 입력 방식 | 필수 | 검사 |
|---|---|---|---|---|
| 1 | 이름 | 글자 입력 | 예 | 공백만 있으면 안 됨 |
| 2 | 전화번호 | 숫자 키패드(`inputmode="tel"`), 010-1234-5678 형태로 자동 하이픈 | 예 | 숫자 10~11자리 |
| 3 | 농지 위치 | 글자 입력 (예: 경북 상주시 ○○면 ○○리). 주소 검색 없음 | 예 | 공백만 있으면 안 됨 |
| 4 | 면적 | 숫자 + 단위 선택(**평** 기본 / ㎡), 또는 "잘 모르겠어요" | 아니오 | 입력하면 0보다 큰 숫자 |
| 5 | 희망 활용 방식 | 큰 선택 카드 하나 고르기: 농가에 임대 · 농작업 위탁 · 체험농장 운영 · 잘 모르겠어요 (상담 원함) | 아니오 | — |

## 6. 우선순위

### P0 — 이번에 구현

- 5단계 질문 화면과 확인 화면, "다음 / 이전" 버튼, "n / 5" 진행 표시
- 5절의 입력 방식과 검사. 필수 항목이 비었거나 형식이 틀리면 다음으로 넘어가지 않고, 입력칸 바로 아래에 쉬운 말로 이유를 보여준다
- 확인 화면: 입력 내용을 크게 표시, 항목마다 "수정" 링크(해당 단계로 돌아갔다가 "확인 화면으로" 버튼으로 바로 복귀), 선택 항목을 건너뛰면 "입력 안 함"으로 표시
- "견본 화면이며 실제로 접수·전송되지 않습니다" 안내와 개인정보 문구(첫 화면, 확인 화면)
- 큰 글자·큰 버튼·높은 대비, 휴대폰 폭에서도 가로 스크롤 없음
- 단계가 바뀌면 질문 제목으로 포커스 이동 (화면 낭독기·키보드 사용자용), Enter로 "다음"
- 저장·전송 없음

### P1 — 다음

- **인쇄하기** 버튼과 인쇄용 스타일: 버튼과 안내를 숨기고 신청서처럼 보이게. 인쇄용 빈 신청서(종이 신청서) 출력
- **전화로 상담하기** 버튼 (`tel:` 링크, 실제 번호 정해지면 교체)
- 면적을 평 ↔ ㎡ 로 함께 표시 (1평 ≈ 3.3058㎡)

### P2 — 나중에

- 글자 크게 보기 토글
- 질문 읽어주기(음성 안내)
- 주소 검색, 실제 접수(서버·저장소 필요 → 개인정보 동의 절차도 함께 설계)

## 7. 수동 테스트

**T1. 정상 흐름**  
1. 이름 "홍길동", 전화번호 `01012345678` 입력 → 화면에 `010-1234-5678`로 표시되는지 확인  
2. 위치 "경북 상주시 외남면", 면적 `300` 평, "농가에 임대" 선택 → "확인"  
3. 확인 화면에 다섯 항목이 그대로 보이고, 견본 안내와 개인정보 문구가 보이면 통과

**T2. 필수 항목·형식 검사**  
1. 이름을 비운 채 "다음" → 넘어가지 않고 "성함을 적어 주세요" 같은 안내가 보이는지 확인  
2. 전화번호에 `0101234` 입력 후 "다음" → 넘어가지 않고 자릿수 안내가 보이는지 확인  
3. 면적 단계에서 "잘 모르겠어요"를 고르고 넘어가면 확인 화면에 "잘 모르겠어요"로 표시되면 통과

**T3. 수정과 저장 없음**  
1. 확인 화면에서 전화번호 "수정" → 번호 변경 → "확인 화면으로" → 바뀐 번호가 보이는지 확인  
2. 페이지를 새로고침 → 첫 화면으로 돌아가고 입력값이 모두 비어 있으면 통과
