# Farmcare WhyTree — 이상준

작성일: 2026-10-29
슬라이드: prototypes/이상준/WhyTree.pptx

아래 들여쓰기의 상위 항목이 why, 하위 항목이 how입니다. 각 항목은 슬라이드의 상자와 같은 문구입니다. [출발점]은 주황색 상자, [새 방법]은 점선 상자입니다. 같은 방법이 여러 목적에 연결되면 아래에 반복 기재하되, 슬라이드에는 상자를 한 번만 그리고 부가 연결을 점선으로 표시합니다.

- 가족의 만족스러운 농촌 체험
  - 체험 선택의 불확실성 줄이기
    - 체험 상품 정보 제공 [출발점]
    - 체험 선택 상담 [새 방법, 주된 목적]
  - 가족에게 적합한 체험 찾기
    - 가족 조건에 맞는 체험 추천 [출발점]
    - 체험 선택 상담 [새 방법, 부가 목적]
  - 참여 신청의 번거로움 줄이기
    - 체험 예약 접수 [출발점]
    - 예약 전 누락 정보 확인 [새 방법, 부가 목적]
  - 방문 준비 부족 줄이기
    - 방문 준비사항 안내 [출발점]
    - 방문 전 준비사항 체크리스트 [새 방법]
- 농장의 안정적인 체험 운영
  - 예약 오류 줄이기
    - 정원·예약 상태 관리 [출발점]
    - 예약 전 누락 정보 확인 [새 방법, 주된 목적]

## 확인 기록

- 다섯 출발점과 목적·새 방법의 문구는 대화에서 작성자가 확인했습니다.
- 메타데이터와 제목은 트리 노드가 아닙니다. 트리 상자는 총 15개입니다.
- 화살표는 수단에서 목적으로, 아래에서 위로 연결합니다.
- 구현 기능은 ‘예약 전 누락 정보 확인’ 노드를 돕습니다.
- AI가 초안을 작성했으며, 작성자는 PPT와 텍스트를 최종 대조해야 합니다. 본 파일이 있다고 대조가 완료된 것으로 간주하지 않습니다.
