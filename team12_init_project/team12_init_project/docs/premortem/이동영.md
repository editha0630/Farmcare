# Farmcare Pre-mortem

Farmcare 프로젝트가 최종적으로 실패했다고 가정하고, 사업 모델을 구성하는 주요 요소 중 프로젝트의 성패에 큰 영향을 줄 수 있는 실패 원인 5가지를 선정했다.

각 실패 원인은 단순한 위험 요소가 아니라, 실제 프로젝트에서 발생할 수 있는 구체적인 사건을 기준으로 무슨 일이 발생했는지, 왜 실패했는지, 언제 실패가 시작되었는지, 왜 사전에 막지 못했는지​를 중심으로 정리하였는데, 신사업기획시 가장 많이 활용하는 비즈니스모델캔버스 **(Business Model Canvas) 프레임워크**을 기반으로 검토하면서 사업이 실패할 수 있는 원인을 도출하고, 그중 가장 근본적인 실패 원인을 확인하는 방식으로 접근하였다.

먼저 비즈니스 캔버스 모델 항목(Customer Segments, Value Proposition, Revenue Streams, Key Partners, Cost Structure, Channels, Key Activities를 중심으로 Farmcare)의 각 항목 영역에서 Farmcare의 사업을 적용하였고, 주요 실패할때 아래와 같이 도출하였다.
