# Farmcare 참여 의향 작성·확인·내보내기

## 실행

index.html 한 파일을 Chrome/Edge로 열면 됩니다. 코드가 모두 HTML에 포함되어 설치·서버·키가 필요 없습니다. interest-core.js와 interest-ui.js는 검사·검토용 동일 소스이며 index.html 실행 시 별도로 불러오지 않습니다.

## 사용

참여 의향 영역에서 이름·참여 유형·관심 체험 입력 → 입력 내용 확인 → 필요하면 수정 → 내용 확정 → 결과 복사 또는 텍스트 파일 다운로드. 연락처를 적을 경우 형식을 확인합니다. 실제 신청 접수·예약·전송·DB 저장은 하지 않습니다. 복사 차단 시 수동 복사 영역을 제공합니다.

## 출처·개인 구현

사용자가 제공한 랜딩페이지의 소개·디자인을 유지하고 개인 기능인 입력 검증·확인·수정·내보내기를 추가했습니다. 원본 전체의 개인 제작 여부는 단정하지 않습니다.
