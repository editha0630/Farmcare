# kardens.io 회고 작성 근거

- WhyTree: 실제 페이지를 기준으로 체험 소개·참여 의향에서 출발했습니다. 이번에 입력 내용 확인 화면을 구현해 점선 상자를 실선으로 바꿨습니다.
- /grill-me: 지침 기반 위임형 검토와 실제 명령 실행을 구분합니다. 실제 명령·상호 인터뷰 미완료입니다.
- 명세서: 입력·검증·확인·수정·복사·다운로드를 P0, 실제 저장·운영 연동을 P2로 정했습니다.
- 구현 후: 원본의 미저장 안내만 있는 양식에서 확인·수정·내보내기 흐름으로 확장했습니다. 로직 11개 및 모의 DOM 검사는 에이전트가 수행했고, 본인의 브라우저 체크는 별도입니다.

가상의 감상·실패·직접 테스트 경험을 작성하지 않습니다. 실제 경험으로 답변을 완성해 제출하세요.
