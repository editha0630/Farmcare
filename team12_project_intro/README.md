**코드를 몰라도 됩니다.** 마크다운(.md) 파일과 사진만 바꾸면 페이지에 자동으로 반영돼요.

## 3. 팀원 소개 고치기 — Team Profiles (`team/TEAM.md`)

농장의 **농가 → 팀원 액자(Team Profiles)** 화면은 전부 `team/TEAM.md` 한 파일에서 만들어집니다.

### 화면의 어느 부분이 어디서 오나요?

```
┌──────────────────────────────┐
│          (동그란 사진)          │ ← - 사진: photos/leedongyoung.jpg
│            이동영              │ ← ## 이동영
│ ┌──────────────────────────┐ │
│ │ 신사업개발 · AI 서비스기획  │ │ ← - 직무: …
│ │       KAIST DFMBA        │ │ ← - 과정: …
│ └──────────────────────────┘ │
│ (신사업개발)(AI서비스기획)…     │ ← - 키워드: a, b, c, d
│ AX 신사업 기획과 AI 에이전트…   │ ← 빈 줄 뒤 소개 문장
│ Problem → Product. …         │ ← - 한 줄: …
│ 개인 페이지 ↗                  │ ← - 개인 페이지: https://…
└──────────────────────────────┘
```

화면 맨 위 안내 문장("Farmcare Team 12가 이 문제를 어떤 관점에서…")은 `TEAM.md`의 `# 팀원 소개` 아래 첫 문단입니다.

### 자주 하는 수정

| 하고 싶은 것 | TEAM.md에서 이렇게 |
|---|---|
| 키워드 하나 바꾸기 | 그 팀원의 `- 키워드:` 줄에서 단어만 바꿉니다. 예: `…, 예산·전략, 금융IT` → `…, 예산·전략, 데이터 분석` |
| 키워드 빼기 | 그 단어와 앞의 쉼표를 지웁니다. 3개만 남아도 괜찮아요. |
| 직무·과정 바꾸기 | `- 직무:` / `- 과정:` 줄의 글자를 바꿉니다. |
| 소개 문장 바꾸기 | 항목 목록 아래 **빈 줄 다음** 문단을 고칩니다. |
| 한 줄 소개 바꾸기 / 없애기 | `- 한 줄:` 줄을 고치거나, 줄째 지웁니다. |
| 개인 페이지 링크 없애기 | `- 개인 페이지:` 줄을 지웁니다. |
| 사진 바꾸기 | 같은 파일 이름으로 `photos/` 에 다시 올리면 끝 (4번). 다른 이름이면 `- 사진:` 줄도 고칩니다. |
| 사진 빼기 | `- 사진:` 줄을 지웁니다(이름 첫 글자가 보여요). |
| 카드 순서 바꾸기 | `## 이름` 부터 다음 `## ` 직전까지를 통째로 잘라 원하는 위치에 붙입니다. |
| 팀원 추가 | 맨 아래에 `## 이름` 묶음을 새로 적습니다(아래 형식). |
| 안내 문장(맨 위) 바꾸기 | `# 팀원 소개` 아래 첫 문단을 고칩니다. |

### GitHub 웹에서 고치는 순서

1. 레포에서 `team12_project_intro` → `team` → `TEAM.md` 를 엽니다.
2. 오른쪽 위 ✏️ **(Edit this file)** 를 누릅니다.
3. 내용을 고칩니다.
4. 오른쪽 위 **Commit changes…** → 메시지(예: `Update 이동영 소개`) 적고 **Commit changes**.
5. 1~3분 뒤 페이지에서 **새로고침(Ctrl + F5)** 하면 반영돼 있어요.

### 적는 형식

팀원 한 명은 `## 이름` 으로 시작합니다. 파일에 적힌 **순서대로** 카드가 놓여요.

```markdown
## 이름
- 직무: 신사업개발 · AI 서비스기획
- 과정: KAIST DFMBA
- 키워드: 키워드1, 키워드2, 키워드3, 키워드4
- 사진: photos/파일이름.jpg
- 개인 페이지: https://아이디.github.io/
- 한 줄: 한 줄 소개 또는 다짐

소개 문장을 2문장 안팎으로 적습니다. (위 목록과 한 줄 띄우기)
```

| 항목 | 화면에서 | 필수 |
|---|---|---|
| `직무` | 초록 칸 첫 줄 | ○ |
| `과정` | 초록 칸 둘째 줄 (예: KAIST PMBA) | |
| `키워드` | 동그란 키워드 칩 — **쉼표(,)로 구분**, 3~4개 권장 | |
| `사진` | 동그란 프로필 사진 (없으면 이름 첫 글자) | |
| `개인 페이지` | 카드 아래 "개인 페이지 ↗" 링크 (`https://` 로 시작) | |
| `한 줄` | 기울임체 한 줄 | |
| `관점` | "이 문제를 바라보는 관점" (선택) | |
| `상태` | `준비 중` 이라고 적으면 점선 '준비 중' 카드 | |
| (빈 줄 뒤 문단) | 소개 문장 | ○ |

- 파일 맨 위 `>` 로 시작하는 안내문은 화면에 보이지 않습니다.
- 카드 모양을 맞추기 위해 **키워드 3~4개, 소개 2문장 안팎**을 지켜 주세요. 직무가 길면 글자가 자동으로 조금 작아지지만, 너무 길면 줄이는 게 좋아요.

### 예: 4번째 팀원 소개가 준비됐을 때

지금은 이렇게 되어 있어요.

```markdown
## 팀원 4
- 상태: 준비 중
```

이 두 줄을 지우고 위 형식대로 바꿔 쓰면 됩니다.

```markdown
## 홍목연
- 직무: …
- 과정: …
- 키워드: …, …, …
- 사진: photos/hongmokyeon.jpg
- 개인 페이지: https://….github.io/
- 한 줄: …

소개 문장 …
```

## 4. 사진 올리기 (`team/photos/`)

1. 레포에서 `team12_project_intro` → `team` → `photos` 폴더로 들어갑니다.
2. 오른쪽 위 **Add file → Upload files** → 사진을 끌어다 놓고 **Commit changes**.
3. `TEAM.md` 에서 그 팀원 항목에 `- 사진: photos/파일이름.jpg` 를 추가합니다(3번 순서대로).

사진 규칙

- **정사각형, 가로세로 240px 정도, 100KB 이하**를 권장해요. (큰 사진도 보이지만 페이지가 느려져요.)
- 파일 이름은 **성이름을 영문 소문자로** 적어요 (예: `hongmokyeon.jpg`, `leesangjune.jpg`).
  - 일련번호(`01.jpg`)는 필요 없어요. 페이지는 `TEAM.md` 에 적힌 파일 이름으로 사진을 찾고, 카드 순서는 `TEAM.md` 에 적힌 순서를 따릅니다.
  - 성만 쓰면(`lee.jpg`) 같은 성의 팀원끼리 사진을 덮어쓸 수 있어요.
  - 한글 이름·띄어쓰기는 피해 주세요. GitHub 주소는 **대소문자를 구분**해서 `Hong.JPG` ↔ `hong.jpg` 가 다르면 사진이 안 나와요.
- 같은 이름으로 다시 올리면 사진이 교체됩니다.

## 5. Questions · Premortem · Project Overview

소개 페이지는 레포의 **공식 문서를 직접 읽어서** 보여줍니다.

| 농장 장소 | 읽는 파일 |
|---|---|
| 작업일지 오두막 (Questions) | `team12_init_project/team12_init_project/docs/QUESTIONS.md` |
| 농기구 창고 (Premortem) | `team12_init_project/team12_init_project/docs/PREMORTEM.md` |
| 농장 운영판 (Project Overview) | `team12_init_project/team12_init_project/docs/PROJECT.md` |

- 수업 과제로 공식 문서를 고치면 **소개 페이지에도 자동으로 바뀝니다.** 복사본을 따로 올릴 필요가 없어요.
- 문서는 쓴 그대로 보여요(제목 `#`, 목록 `-`, 표 `| |`, 굵게 `**` 등 일반 마크다운).
- ⚠️ 위 **폴더 이름이나 파일 이름을 바꾸거나 옮기면** 소개 페이지가 문서를 못 찾아요. 바꿔야 한다면 담당자에게 먼저 알려 주세요.

## 6. 반영이 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 고쳤는데 그대로예요 | 1~3분 기다린 뒤 **Ctrl + F5** (강력 새로고침). 레포 **Actions** 탭에서 `pages build and deployment` 가 초록 ✓ 인지 확인 |
| 팀원 카드가 이상하게 나와요 | `## 이름` 앞에 빈 줄이 있는지, `- 항목: 값` 에서 **콜론(:)** 을 빠뜨리지 않았는지, 소개 문장 앞에 빈 줄이 있는지 |
| 사진이 안 나와요 | `photos/` 안의 실제 파일 이름과 `- 사진:` 에 적은 이름이 **대소문자·확장자까지** 같은지 (`.jpg` / `.jpeg` / `.png`) |
| 자료 창에 "자료를 불러오지 못했어요" | 공식 문서의 폴더·파일 이름이 바뀌지 않았는지 (5번) |

## 7. 하지 말아 주세요

- `index.html` 직접 수정 — 코드가 한 파일에 합쳐져 있어 손으로 고치기 어렵고, 다음 업데이트 때 덮어써집니다.
- `team12_project_intro`, `team`, `photos` 폴더 이름 바꾸기 — 주소와 경로가 깨집니다.
- **비식별 원칙**
  - 회사명 등 소속을 특정할 수 있는 이름은 쓰지 않고 "반도체 대기업"처럼 일반화합니다.
  - 얼굴 사진은 **본인이 동의한 경우에만** 올립니다. (이 레포는 공개 레포라 누구나 볼 수 있어요.)

페이지 원본(코드)은 담당자 컴퓨터의 `farmcare` 폴더에 있습니다. 원본을 고친 뒤

```
python tools/build_share.py --pages
```

를 실행하면 `upload/team12_project_intro/` 가 새로 만들어집니다. 그중 **`index.html` 만** 레포의 같은 위치에 다시 올리면 돼요. (`team/` 은 레포 쪽이 최신일 수 있으니 덮어쓰지 마세요.)
